# dior-fans-interact-docs

Customer guide for the YOLO by Dior Music Pop Up Event keepsake card experience, built with MkDocs and published on GitHub Pages.

Live site: https://jacksen-ng.github.io/dior-fans-interact-docs/

## Preview locally

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/mkdocs serve
```

Pages live in `docs/`, the menu is set in `mkdocs.yml`. Every push to `main` rebuilds and publishes the site through GitHub Actions.
