# Event Day Guide

A step-by-step checklist for staff running the experience at the venue.

## Before doors open

1. **Set up the Big Screen.**
    - On the display computer, open [dior-fans-interact.vercel.app/screen](https://dior-fans-interact.vercel.app/screen) in Chrome.
    - Switch the browser to full screen (press F11 on Windows, or Control + Command + F on Mac).
    - **Click the screen once** so the background music can start.
    - Keep this page in front. Do not minimise it or switch to another tab, otherwise it stops updating.
2. **Open the Staff Console.**
    - On a separate computer or phone, open [dior-fans-interact.vercel.app/admin](https://dior-fans-interact.vercel.app/admin) and sign in with the staff key.
3. **Check the settings.**
    - Mode: **Auto** for a continuous flow of cards, **Manual** to release cards in batches at chosen moments.
    - Cards on screen at once, display seconds and fly-in time.
    - Big screen music: on or off.
4. **Do a test run.**
    - Scan the QR code with a phone and submit a test card.
    - Check that it appears on the big screen.
    - Then **Hide** the test card in the console so it is not shown again.

## During the event

- Keep an eye on the card list. **Hide** any card with an inappropriate name; it leaves the big screen immediately.
- Use **Clear screen** for a clean moment, for example before an announcement. In auto mode, press **Resume** afterwards to continue.
- If a guest would like to see their card again, find it by name or day count and press **Show again**.
- When there are few new cards, turn on **Replay released cards** to keep the big screen lively.

## If something goes wrong

| Problem | What to try |
| --- | --- |
| No new cards appear on the big screen | Check the big screen page is open and in front. In the console, check for *Screen paused* (press **Resume**) and whether the mode is **Manual** (press **Release**). |
| No sound on the big screen | Click the big screen page once. Check **Big screen music** is on in the console, and check the computer's volume and speakers. |
| Console shows *Connection lost, retrying* | Check the internet connection. The console reconnects by itself. |
| A guest's Submit fails | Ask the guest to press **Try again**. It will not create a duplicate card. If it keeps failing, check the venue's mobile signal or Wi-Fi. |
| The big screen was refreshed by accident | Nothing to do. It returns to the same cards and remaining time by itself. Click it once again to restore sound. |
| Guest cannot save the picture | On phones, choose "Save Image" in the share menu that appears. If no menu appears, tap **Save card** again. |
